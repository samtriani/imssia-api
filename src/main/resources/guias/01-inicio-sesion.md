# Inicio de Sesión en ECSUS

ECSUS (Expediente Clínico del Sistema Universal de Salud) es el sistema
clínico que el médico utiliza para atender a sus pacientes. Esta sección
explica cómo iniciar sesión, qué hacer si las credenciales son inválidas y
cómo restablecer o actualizar la contraseña.

## Iniciar sesión
1. Ingresar Matrícula y Contraseña (la contraseña inicial es la misma
   matrícula).
2. Seleccionar "Ingresar".
3. Si las credenciales son inválidas, el sistema mostrará un mensaje de
   error y no permitirá el acceso.

![Pantalla de inicio de sesión de ECSUS](/assets/guias/ecsus-medico/slide05.png)

## Restablecer contraseña (olvidé mi contraseña)
1. En la pantalla de inicio de sesión, seleccionar "Olvidé mi contraseña".
2. Ingresar la Matrícula.
3. Seleccionar "Restablecer" para iniciar el cambio de contraseña.

![Pantalla para restablecer la contraseña olvidada](/assets/guias/ecsus-medico/slide05.png)

## Actualizar contraseña
1. Ingresar Matrícula y Contraseña, y seleccionar "Ingresar".
2. El sistema dirige automáticamente a la pantalla de Cambio de Contraseña.
3. Ingresar la Contraseña actual.
4. Ingresar la Nueva Contraseña.
5. Confirmar la Nueva Contraseña.

> **Nota:** la contraseña debe tener entre 7 y 12 caracteres, incluir al
> menos una letra mayúscula y caracteres especiales, y no debe contener
> números consecutivos.

![Pantalla de actualización de contraseña](/assets/guias/ecsus-medico/slide06.png)
