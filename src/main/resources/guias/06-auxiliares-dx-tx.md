# Auxiliares de Diagnóstico y Tratamiento en ECSUS

Esta sección explica cómo generar una Receta, una Solicitud de Laboratorio
y una Solicitud de Rayos X desde el módulo de Auxiliares de Dx y Tx.

## Receta
1. Seleccionar "Acciones".
2. Seleccionar "Receta" dentro de Auxiliares de Dx y Tx.

![Pantalla para abrir el módulo de Receta](/assets/guias/ecsus-medico/slide44.png)

3. Buscar el medicamento por nombre.

![Pantalla de búsqueda de medicamento](/assets/guias/ecsus-medico/slide45.png)

4. Seleccionar el medicamento de los resultados.
5. Indicar los datos de prescripción.
6. Seleccionar "Agregar Medicamento".

![Pantalla para indicar datos de prescripción y agregar el medicamento](/assets/guias/ecsus-medico/slide46.png)

7. Seleccionar "Registrar Receta".
8. Seleccionar "Imprimir receta".

![Pantalla para registrar e imprimir la receta](/assets/guias/ecsus-medico/slide47.png)

## Solicitud de Laboratorio
1. Seleccionar "Acciones".
2. Seleccionar "Solicitud de Laboratorio" dentro de Auxiliares de Dx y Tx.

![Pantalla para abrir Solicitud de Laboratorio](/assets/guias/ecsus-medico/slide48.png)

3. Seleccionar el tipo de orden.
4. Seleccionar "Estudios Frecuentes" o "Solicitud básica de estudios".
5. Seleccionar "Agregar Estudio".
6. Seleccionar "Registrar Solicitud" (o "Cancelar").

![Pantalla para seleccionar y agregar estudios de laboratorio](/assets/guias/ecsus-medico/slide49.png)

7. Seleccionar "Imprimir" para imprimir la solicitud registrada.

![Pantalla para imprimir la solicitud de laboratorio](/assets/guias/ecsus-medico/slide50.png)

## Solicitud de Rayos X
1. Seleccionar "Acciones".
2. Seleccionar "Solicitud de Rayos X" dentro de Auxiliares de Dx y Tx.

![Pantalla para abrir Solicitud de Rayos X](/assets/guias/ecsus-medico/slide51.png)

3. Seleccionar el tipo de orden.
4. Seleccionar el "Grupo o Región" y el "Estudio".
5. Seleccionar "Agregar Estudio".
6. Seleccionar "Registrar Solicitud".

![Pantalla para seleccionar y agregar el estudio de rayos X](/assets/guias/ecsus-medico/slide52.png)

7. Seleccionar "Imprimir" para imprimir la solicitud registrada.

![Pantalla para imprimir la solicitud de rayos X](/assets/guias/ecsus-medico/slide53.png)
