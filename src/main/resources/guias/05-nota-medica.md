# Nota Médica en ECSUS

Esta sección explica cómo crear una Nota Médica: el resumen clínico, el
diagnóstico, la consulta de notas previas y cómo agregar un addendum.

## Crear una nueva Nota Médica
1. Con el paciente en atención, seleccionar el menú de puntos (⋮).
2. Seleccionar "Nota Médica".
3. Seleccionar "Nueva Nota Médica".

![Pantalla para crear una nueva nota médica](/assets/guias/ecsus-medico/slide34.png)

## Resumen Clínico
1. Indicar si se va a registrar somatometría: "Sí" o "No" (se elige "No"
   solo en los casos donde no se requiere registrar esta información).
2. Ingresar la "Exploración Física".

![Pantalla de resumen clínico - somatometría y exploración física](/assets/guias/ecsus-medico/slide35.png)

3. Ingresar el "Padecimiento actual o motivo de la consulta".
4. Registrar la "Descripción de la exploración física".
5. Seleccionar "Registrar resumen Clínico" (o "Cancelar").

![Pantalla de resumen clínico - padecimiento actual](/assets/guias/ecsus-medico/slide36.png)

## Diagnóstico
1. Buscar el diagnóstico CIE10 en la barra de búsqueda.
2. Seleccionar "Primera Vez" o "Subsecuente".
3. Seleccionar el "Tipo de Diagnóstico".
4. Registrar el "Complemento de diagnóstico".
5. Seleccionar "Agregar Diagnóstico".
6. Los diagnósticos agregados se visualizan en "Información Registrada".

![Pantalla de diagnóstico - búsqueda CIE10](/assets/guias/ecsus-medico/slide37.png)

7. Buscar la "Ocupación" del paciente.
8. Seleccionar el "Lugar del accidente" (si aplica).
9. Buscar el "Procedimiento CIE9".
10. Seleccionar el "Tipo de Procedimiento".
11. Seleccionar "Agregar".

> **Nota:** el campo "Otra" es de texto libre para cuando el dato requerido
> no está en el catálogo.

![Pantalla de diagnóstico - ocupación y procedimiento](/assets/guias/ecsus-medico/slide38.png)

12. Seleccionar las "Indicaciones higiénico-dietéticas y observaciones".
13. El sistema muestra los datos del médico.
14. Seleccionar "Guardar Nota Médica".
15. Usar la opción "Cancelar" si no se desea guardar.

> **Nota:** el campo "Observaciones" es de texto libre para cuando el dato
> requerido no está en el catálogo.

![Pantalla de diagnóstico - indicaciones y guardado](/assets/guias/ecsus-medico/slide39.png)

## Guardar y Consultar Notas
16. Seleccionar "Guardar Nota Médica".
17. En la portada del expediente del paciente se pueden consultar las
    notas médicas ya realizadas.

![Pantalla de consulta de notas médicas](/assets/guias/ecsus-medico/slide40.png)

## Addendum
1. Para agregar información adicional a una nota ya guardada, seleccionar
   "Opciones de nota médica" y elegir "Addendum".
2. Para imprimir, seleccionar "Imprimir Nota"; se imprimirá la nota
   seleccionada.

![Pantalla para agregar un addendum o imprimir la nota](/assets/guias/ecsus-medico/slide42.png)
